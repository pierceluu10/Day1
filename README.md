# Day One

An onboarding agent for new hires, built today for the MongoDB hackathon (Track 3, "Finish the Job"). It sets up a new hire's Git account (browser) and laptop (terminal) until the team's tests pass, verifies every step independently, resumes after a crash without repeating work, adapts when the repository changes mid-setup, and remembers every error-and-fix in MongoDB Atlas so the next hire never solves it again.

Status: in progress. See `docs/BRIEF.md`, `docs/DEMO.md` and `STATUS.md`.

`demo_repo/` (`acme-api`) is a demo service built today to mirror common onboarding problems.
